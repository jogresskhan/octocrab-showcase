# Security Policy

## Supported versions

The latest tagged release of octocrab-showcase receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub security advisories](https://github.com/jogresskhan/octocrab-showcase/security/advisories/new)
or contact jogresskhan@gmail.com directly. Please do not open public issues for
security problems. Expect an initial response within 7 days.
